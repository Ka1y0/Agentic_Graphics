# Changelog

## Unreleased

- Evolved the project brand and repository from `agentic_graphics` to `Agentic_Graphics` while preserving the `agentic_graphics` import, `agentic-graphics` distribution, and `agfx` CLI.
- Added the project vision, conceptual project map, maturity-based roadmap, Worlds, and Labs documentation.
- Added Pixel Harbor as the first Featured World: a standalone Three.js reference project with six render styles, four seasons, day/night simulation, procedural audio, NPC behavior, and reversible 2D/3D presentation.
- Added an optimized screenshot gallery, technical case study, third-party notices, locked frontend dependencies, and public/debug presentation modes.
- Added Pixel Harbor CI and an official GitHub Pages build/deployment pipeline with a minimal root landing page.

## 0.1.0-alpha.1

- Added GraphicsSpec v1 and composable workflow graph resolution.
- Added provider-neutral manual, command, and optional OpenAI-compatible LLM adapters.
- Added manual input, Modly automation/handoff, and Blender procedural generation adapters.
- Added Blender processing, validation, reports, and generated-code execution controls.
- Added Unreal command-line Python ingestion with bounded `/Game/...` destinations.
- Added run events, SHA-256 manifests, provenance, doctor, dry-run, tests, and future 2D/2.5D/NPR architecture documents.
