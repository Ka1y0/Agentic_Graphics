# Worlds

Worlds are complete interactive reference projects built through Agentic_Graphics workflows. They are larger than examples and may contain their own runtime, renderer, and toolchain.

| Area | Purpose |
|---|---|
| `examples/` | Small, deterministic, testable demonstrations of a focused Core behavior. |
| `worlds/` | Complete interactive projects with their own visual system and runtime. |
| `labs/` | Research directions and experiments that are not general Core capabilities. |

## Featured World

### [Pixel Harbor](pixel_harbor/)

Pixel Harbor is the first featured world: a standalone Three.js reference project developed through an agentic graphics workflow. It demonstrates how an iterative workflow can grow into a complete interactive visual world; it is not generated automatically by the Agentic_Graphics Python Core.

- [Live demo](https://ka1y0.github.io/Tool_Agentic_Graphics/pixel-harbor/)
- [Technical case study](../docs/showcases/pixel-harbor.md)
