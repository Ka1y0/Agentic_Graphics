# Future 2.5D architecture

The intended 2.5D graph is:

```text
Agent → layers / depth / sprites / cards
      → Blender or engine scene construction
      → camera and parallax validation → real-time output
```

Candidate artifacts include depth maps, camera-facing geometry, billboards, layered scenes, sprite/mesh combinations, and image-to-scene reconstructions. Validation should cover layer order, depth scale, camera constraints, parallax ranges, transparency, occlusion, and target-engine cost.

No 2.5D scene builder is implemented in 0.1. The graph, artifact, validation, and provenance contracts are designed to accept it later.
