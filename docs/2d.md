# Future 2D architecture

The intended 2D graph is:

```text
Agent → GraphicsSpec → image generator or procedural renderer
      → image/compositing validation → output + provenance
```

Future artifacts may include illustrations, textures, sprites, concept art, UI assets, animation frames, masks, and composites. Useful validators include pixel dimensions, color space, alpha semantics, frame consistency, compression, and license/provenance completeness.

No 2D generator or compositor adapter is implemented in 0.1. `representation.type: 2d` is a stable schema entry, not a fake capability claim.
