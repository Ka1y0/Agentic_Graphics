# Security Policy

## Supported versions

The latest tagged 0.1 prerelease receives security fixes. Earlier snapshots may not.

## Reporting

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish credentials, private asset paths, proprietary files, or an active exploit in a public issue.

Agentic_Graphics does not claim to sandbox generated Python or DCC/engine plugins. If a report depends on OS-level isolation, clearly state the assumed trust boundary and execution environment.
